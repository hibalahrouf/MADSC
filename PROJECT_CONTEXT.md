# Project Context — Mogador PFA

**Status:** Repository reconstruction, 18 July 2026. This is a factual context record, not a design recommendation.

## Project objective

- **High confidence — repository and current user scope:** The project is a final-year Purple Team lab for the fictional `mogador.local` hotel environment. Its current scope is secure Active Directory architecture, AD hardening, audit, attack-path analysis, logging, SIEM integration, and detection engineering for AD-related attacks.
- **High confidence — current user scope:** PMS penetration testing, web application testing, and PMS vulnerability assessment are cancelled and out of scope, even though older project documents retain them.
- **High confidence — user decision, 18 July 2026:** `PMS-01` remains in the lab only as a normal Tier 1 business server. The AD-hardening work will be structured using a scoped ISO/IEC 27001:2022-aligned risk-treatment approach; this is not a claim of ISO certification or a full ISMS implementation.

- **High confidence — current session context and difference report:** VMware Workstation hosts a four-VM lab, with GNS3 Cloud nodes and a Cisco router used for topology/learning. The active lab subnet is `192.168.10.0/24`; Kali also has NAT connectivity.
